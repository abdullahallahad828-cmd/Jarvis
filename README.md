# Jarvis App - সেটআপ গাইড

## এই অ্যাপ যা করে
- মাইক বাটনে চাপ দিলে ভয়েস কমান্ড শোনে (বাংলা)
- "রহিমকে কল করো" বললে → ফোনের কন্টাক্ট থেকে রহিমের নাম্বার খুঁজে সরাসরি নরমাল কল করে
- "রহিমকে হোয়াটসঅ্যাপে কল করো" বললে → WhatsApp-এ রহিমের চ্যাট/কল স্ক্রিন খুলে দেয়

## যেভাবে চালাবেন (দুইটা পথ)

### পথ A: শুধু মোবাইল/ব্রাউজার দিয়ে (GitHub Actions ব্যবহার করে APK বানানো)
1. ফোনের ব্রাউজারে **github.com**-এ গিয়ে একটা ফ্রি অ্যাকাউন্ট খুলুন
2. একটা নতুন **Repository** বানান (Public/Private যেকোনো একটা, নাম দিন যেমন `jarvis-app`)
3. এই পুরো `JarvisApp` ফোল্ডারের সব ফাইল সেই repository-তে আপলোড করুন — GitHub-এর "Add file > Upload files" বাটন দিয়ে (পুরো ফোল্ডার স্ট্রাকচার ঠিক রেখে আপলোড করতে হবে, অর্থাৎ `app/src/main/java/...` এই path গুলো ঠিক রাখতে হবে)
4. আপলোড হয়ে গেলে GitHub স্বয়ংক্রিয়ভাবে `.github/workflows/build.yml` ফাইলটা দেখে বিল্ড শুরু করবে
5. Repository-এর উপরে **Actions** ট্যাবে গিয়ে দেখুন বিল্ড চলছে (কয়েক মিনিট লাগবে, সবুজ ✓ চিহ্ন আসলে বিল্ড সফল)
6. বিল্ড শেষ হলে সেই Action-এর ভেতরে নিচে **Artifacts** সেকশনে `jarvis-app-debug-apk` নামে একটা ফাইল পাবেন — সেটা ডাউনলোড করুন (এটা একটা zip, ভেতরে APK থাকবে)
7. zip থেকে APK বের করে ফোনে ইনস্টল করুন (ফোনে "Unknown apps install" পারমিশন চাইতে পারে, Allow করুন)

### পথ B: PC/Laptop দিয়ে Android Studio (যদি এক্সেস থাকে)
1. **Android Studio** ওপেন করুন (না থাকলে ফ্রি ডাউনলোড: developer.android.com/studio)
2. `File > Open` করে এই `JarvisApp` ফোল্ডারটা সিলেক্ট করুন
3. Gradle sync হতে দিন (প্রথমবার একটু সময় লাগবে, ইন্টারনেট লাগবে)
4. একটা Android ফোন USB দিয়ে কানেক্ট করুন (Developer Options + USB Debugging অন করতে হবে), অথবা Emulator ব্যবহার করুন
5. উপরে সবুজ **Run ▶** বাটনে চাপ দিন
6. প্রথমবার চালানোর সময় ফোন Microphone, Call, Contacts পারমিশন চাইবে — সবগুলো Allow করুন

## জরুরি বাস্তবতা
- **WhatsApp অটো-কল সরাসরি বাটনে চাপ ছাড়া সম্ভব না** (কোনো official API নেই)। এই কোড WhatsApp-এর চ্যাট/কল স্ক্রিন পর্যন্ত খুলে দেয়, শেষ ধাপে (কল বাটনে চাপ) আপনাকে নিজে করতে হবে। এটা এড়াতে হলে Accessibility Service লাগবে, যেটা জটিল এবং Play Store policy-violation হতে পারে — শুধু personal ব্যবহারের জন্য সম্ভব, চাইলে বলবেন, এটাও বানিয়ে দেব।
- **নরমাল কল** পুরোপুরি অটোমেটিক — পারমিশন দিলে সরাসরি ডায়াল হয়ে যাবে, কোনো ক্লিক লাগবে না
- নাম শনাক্তকরণ (`extractName` ফাংশন) এখন খুবই সাধারণ লজিকে করা — আরও নির্ভুল করতে চাইলে জানাবেন

## পরবর্তী ধাপে যা যোগ করা যায় (চাইলে বলবেন)
- "সবসময় শোনা" (wake word যেমন "Hey Jarvis") মোড
- SMS পাঠানো, অ্যালার্ম সেট করা, Wi-Fi/Bluetooth অন-অফ করা
- অন্য অ্যাপ (Facebook, YouTube ইত্যাদি) ওপেন করা কমান্ড
